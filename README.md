# MugShot

**MugShot** is an Elder Scrolls Online (ESO) target unit frame addon that replaces the default reticle-over target frame (`ZO_TargetUnitFramereticleover`) with a modern, high-visibility, combat-ready target frame inspired by Hyperioxes' *TargetFrame*.
